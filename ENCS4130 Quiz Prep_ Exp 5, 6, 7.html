BGP basics

  • IGP (RIP, OSPF, EIGRP) routes inside one AS. BGP is the EGP between ASes. It is a path vector protocol: the AS Path is the key attribute, and a router that sees its own AS in the path drops the route (loop prevention).
  • AS numbers: public 1 to 64,511, private 64,512 to 65,535. One BGP process per Cisco router.
  • BGP is worth it with multiple external links or inbound policy control. Full table once, then incremental updates only.

Session states (memorize the order)

Trap. Stuck in Active means: no IP connectivity, wrong neighbor IP or AS number, or an ACL/firewall blocking TCP 179. A NOTIFICATION sends any state back to Idle.

DNS

  • UDP 53 by default, TCP 53 when the answer is too big.
  • Recursive: server does all the work. Iterative: server returns a referral. Local resolver is recursive toward the host, iterative toward the hierarchy.
  • Records: A (name to IP), CNAME (alias), MX (mail server).
  • ping pc3 sends a DNS query/reply first, then ICMP.

Web request order: DNS lookup, then TCP three-way handshake (SYN, SYN-ACK, ACK), then HTTP GET, then response. Email order: DNS, TCP, SMTP to the server, later POP3 by the recipient. Address format user@domain; the mail client's incoming and outgoing server is the domain name.

Switch logic and the 802.1Q tag

Learn source MAC, look up destination, then: known on another port, forward; known on the same port, drop; unknown, flood every port except the incoming one.
  • VIDs: 0 and 4095 reserved, 1 default, 2 to 4094 usable.
  • The only thing you must specify to create a VLAN is the VLAN ID.
  • Every switch must have every VLAN created, or it drops that VLAN's frames. Assigning a port to a missing VLAN auto-creates it.
  • Different VLANs are different subnets, so they need a Layer 3 device.

Trap (Quiz 3). Wrong options use: the serial interface, encapsulation under the physical interface, no encapsulation line, or a wildcard mask (0.0.0.255) on an IP address.

Method 2: Layer 3 switch (SVI)

ip routing                            ! OFF by default
vlan 60
interface vlan 60                     ! SVI = gateway for VLAN 60
 ip address 192.X.60.1 255.255.255.0
interface Fa0/1
 no switchport                        ! routed port
 ip address 192.X.0.5 255.255.255.252
interface Fa0/2                       ! trunk to a Layer 2 switch
 switchport trunk encapsulation dot1q ! L3 side only
 switchport mode trunk

Pros: fast, routes inter-VLAN internally. Cons: expensive, no WAN interfaces, less flexible than a router.

! Layer 2 switch
vlan 10
interface Fa2/1

interface Fa1/1

Tracing paths: ask these in order

  1. Same VLAN? Pure Layer 2, no router. Quiz 3: PC1 and PC6 are both VLAN 20, so the path is PC1, S0, S1, S2, PC6.
  2. Different VLANs, same router? Up to the router and back down the same trunk. PC0 to PC6: PC0, SW0, R0, SW0, SW1, SW2, PC6.
  3. Different routers? Cross the router link. PC0 to PC5: PC0, SW0, R0, R1, SW2, PC5.
